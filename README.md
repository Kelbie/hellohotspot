# HelloHotspot

Pay-as-you-go eSIM data from silent.link, paid from a built-in Cashu wallet.

[Website and Android download](https://gethellohotspot.com)

This repository contains public distribution metadata for Zapstore developer verification.
The application source and internal GitHub releases are held in a separate private repository.
The app is independent of silent.link.

The Android application ID is `com.gethellohotspot`.
